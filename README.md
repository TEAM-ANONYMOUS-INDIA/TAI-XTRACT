# 🔍 Features

✅ Website Intelligence Gathering

Finds IP Address & DNS Records

Detects Subdomains

Identifies CMS & Technology Stack

Extracts JavaScript Files & API Endpoints

Finds Open Ports & Running Services

Detects Web Application Firewall (WAF)

Analyzes HTTP Headers & Cookies

Finds Admin Panel & Login Pages

Scans for SQL Injection Points & Databases

Extracts Wayback Machine Data for Hidden Endpoints

💻 Installation

### 🔹 Linux & Termux Installation
```
git clone https://github.com/TEAM-ANONYMOUS-INDIA/TAI-XTRACT.git
cd TAI-XTRACT
pip install -r requirements.txt
python3 TAI-XTRACT.py
```
### 🔹 Windows Installation

```
git clone https://github.com/TEAM-ANONYMOUS-INDIA/TAI-XTRACT.git
cd TAI-XTRACT
pip install -r requirements.txt
python3 TAI-XTRACT.py
```
